# The Reactivity Series

The reactivity series is a list of metals arranged in the order of their decreasing activities.

| Metal | Symbol | Reactivity |
| :--- | :---: | :--- |
| Potassium | K | Most reactive |
| Sodium | Na | |
| Calcium | Ca | |
| Magnesium | Mg | |
| Aluminium | Al | |
| Zinc | Zn | Reactivity decreases |
| Iron | Fe | |
| Lead | Pb | |
| **[Hydrogen]** | **[H]** | |
| Copper | Cu | |
| Mercury | Hg | |
| Silver | Ag | |
| Gold | Au | Least reactive |

{: .note }
> **Key Points:**
> - Metals above hydrogen in the series can displace hydrogen from dilute acids.
> - Metals below hydrogen cannot displace hydrogen from dilute acids.
> - A metal higher in the series can displace a metal lower in the series from its salt solution.
> - K, Na, Ca, Mg are so reactive they are never found free in nature.
> - Cu, Ag, Au are so unreactive they are found in native (free) state.
