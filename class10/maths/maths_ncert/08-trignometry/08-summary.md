## 8.5 Summary

In this chapter, you have studied the following points :

1. In a right triangle ABC, right-angled at B,
   - $\sin A = \dfrac{\text{side opposite to angle A}}{\text{hypotenuse}}$, $\cos A = \dfrac{\text{side adjacent to angle A}}{\text{hypotenuse}}$
   - $\tan A = \dfrac{\text{side opposite to angle A}}{\text{side adjacent to angle A}}$.

2. $\text{cosec } A = \dfrac{1}{\sin A}$; $\sec A = \dfrac{1}{\cos A}$; $\tan A = \dfrac{1}{\cot A}$; $\tan A = \dfrac{\sin A}{\cos A}$.

3. If one of the trigonometric ratios of an acute angle is known, the remaining trigonometric ratios of the angle can be easily determined.

4. The values of trigonometric ratios for angles $0^\circ$, $30^\circ$, $45^\circ$, $60^\circ$ and $90^\circ$.

5. The value of sin A or cos A never exceeds 1, whereas the value of sec A ($0^\circ \le A < 90^\circ$) or cosec A ($0^\circ < A \le 90^\circ$) is always greater than or equal to 1.

6. $\sin^2 A + \cos^2 A = 1$,
   - $\sec^2 A - \tan^2 A = 1$ for $0^\circ \le A < 90^\circ$,
   - $\text{cosec}^2 A = 1 + \cot^2 A$ for $0^\circ < A \le 90^\circ$.
