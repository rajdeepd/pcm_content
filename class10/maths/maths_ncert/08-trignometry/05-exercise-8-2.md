## EXERCISE 8.2

1. Evaluate the following :

   - (i) $\sin 60^\circ \cos 30^\circ + \sin 30^\circ \cos 60^\circ$
   - (ii) $2 \tan^2 45^\circ + \cos^2 30^\circ - \sin^2 60^\circ$
   - (iii) $\dfrac{\cos 45^\circ}{\sec 30^\circ + \text{cosec } 30^\circ}$
   - (iv) $\dfrac{\sin 30^\circ + \tan 45^\circ - \text{cosec } 60^\circ}{\sec 30^\circ + \cos 60^\circ + \cot 45^\circ}$
   - (v) $\dfrac{5 \cos^2 60^\circ + 4 \sec^2 30^\circ - \tan^2 45^\circ}{\sin^2 30^\circ + \cos^2 30^\circ}$

2. Choose the correct option and justify your choice :

   - (i) $\dfrac{2 \tan 30^\circ}{1 + \tan^2 30^\circ} =$ (A) $\sin 60^\circ$ (B) $\cos 60^\circ$ (C) $\tan 60^\circ$ (D) $\sin 30^\circ$
   - (ii) $\dfrac{1 - \tan^2 45^\circ}{1 + \tan^2 45^\circ} =$ (A) $\tan 90^\circ$ (B) 1 (C) $\sin 45^\circ$ (D) 0
   - (iii) $\sin 2A = 2 \sin A$ is true when A = (A) $0^\circ$ (B) $30^\circ$ (C) $45^\circ$ (D) $60^\circ$
   - (iv) $\dfrac{2 \tan 30^\circ}{1 - \tan^2 30^\circ} =$ (A) $\cos 60^\circ$ (B) $\sin 60^\circ$ (C) $\tan 60^\circ$ (D) $\sin 30^\circ$

3. If $\tan (A + B) = \sqrt{3}$ and $\tan (A - B) = \dfrac{1}{\sqrt{3}}$; $0^\circ < A + B \le 90^\circ$; A > B, find A and B.

4. State whether the following are true or false. Justify your answer.
   - (i) $\sin (A + B) = \sin A + \sin B$.
   - (ii) The value of $\sin \theta$ increases as $\theta$ increases.
   - (iii) The value of $\cos \theta$ increases as $\theta$ increases.
   - (iv) $\sin \theta = \cos \theta$ for all values of $\theta$.
   - (v) cot A is not defined for A = $0^\circ$.

---

## Solutions

**1.**

- (i) $\sin 60^\circ \cos 30^\circ + \sin 30^\circ \cos 60^\circ = \dfrac{\sqrt{3}}{2} \cdot \dfrac{\sqrt{3}}{2} + \dfrac{1}{2} \cdot \dfrac{1}{2} = \dfrac{3}{4} + \dfrac{1}{4} = 1$.
- (ii) $2 \tan^2 45^\circ + \cos^2 30^\circ - \sin^2 60^\circ = 2(1)^2 + \left(\dfrac{\sqrt{3}}{2}\right)^2 - \left(\dfrac{\sqrt{3}}{2}\right)^2 = 2 + \dfrac{3}{4} - \dfrac{3}{4} = 2$.
- (iii) $\sec 30^\circ = \dfrac{2}{\sqrt{3}}$, $\text{cosec } 30^\circ = 2$, so $\sec 30^\circ + \text{cosec } 30^\circ = \dfrac{2}{\sqrt{3}} + 2 = \dfrac{2 + 2\sqrt{3}}{\sqrt{3}}$. Hence $\dfrac{\cos 45^\circ}{\sec 30^\circ + \text{cosec } 30^\circ} = \dfrac{1/\sqrt{2}}{(2 + 2\sqrt{3})/\sqrt{3}} = \dfrac{\sqrt{3}}{\sqrt{2}(2 + 2\sqrt{3})} = \dfrac{\sqrt{3}}{2\sqrt{2}(1 + \sqrt{3})}$. Rationalising, this equals $\dfrac{\sqrt{3}(\sqrt{3}-1)}{4\sqrt{2}}$ (after simplifying).
- (iv) $\sin 30^\circ + \tan 45^\circ - \text{cosec } 60^\circ = \dfrac{1}{2} + 1 - \dfrac{2}{\sqrt{3}} = \dfrac{3}{2} - \dfrac{2}{\sqrt{3}}$. $\sec 30^\circ + \cos 60^\circ + \cot 45^\circ = \dfrac{2}{\sqrt{3}} + \dfrac{1}{2} + 1 = \dfrac{2}{\sqrt{3}} + \dfrac{3}{2}$. The ratio simplifies to $\dfrac{3\sqrt{3} - 4}{4 + 3\sqrt{3}}$; on rationalising, $\dfrac{43 - 24\sqrt{3}}{11}$.
- (v) $5 \cos^2 60^\circ + 4 \sec^2 30^\circ - \tan^2 45^\circ = 5 \cdot \dfrac{1}{4} + 4 \cdot \dfrac{4}{3} - 1 = \dfrac{5}{4} + \dfrac{16}{3} - 1 = \dfrac{15 + 64 - 12}{12} = \dfrac{67}{12}$. Denominator $\sin^2 30^\circ + \cos^2 30^\circ = 1$. So the value is $\dfrac{67}{12}$.

**2.**

- (i) $\tan 30^\circ = \dfrac{1}{\sqrt{3}}$, so $1 + \tan^2 30^\circ = 1 + \dfrac{1}{3} = \dfrac{4}{3}$. Hence $\dfrac{2 \tan 30^\circ}{1 + \tan^2 30^\circ} = \dfrac{2/\sqrt{3}}{4/3} = \dfrac{3}{2\sqrt{3}} = \dfrac{\sqrt{3}}{2} = \sin 60^\circ$. **(A)**
- (ii) $\dfrac{1 - \tan^2 45^\circ}{1 + \tan^2 45^\circ} = \dfrac{1 - 1}{1 + 1} = 0$. **(D)**
- (iii) $\sin 2A = 2 \sin A$ when $2\sin A \cos A = 2\sin A$, i.e. $\cos A = 1$ or $\sin A = 0$, so $A = 0^\circ$. **(A)**
- (iv) $\dfrac{2 \tan 30^\circ}{1 - \tan^2 30^\circ} = \dfrac{2/\sqrt{3}}{1 - 1/3} = \dfrac{2/\sqrt{3}}{2/3} = \sqrt{3} = \tan 60^\circ$. **(C)**

**3.** $\tan (A + B) = \sqrt{3}$ $\Rightarrow$ $A + B = 60^\circ$. $\tan (A - B) = \dfrac{1}{\sqrt{3}}$ $\Rightarrow$ $A - B = 30^\circ$. Adding: $2A = 90^\circ$ $\Rightarrow$ $A = 45^\circ$. Then $B = 60^\circ - 45^\circ = 15^\circ$.

**4.**

- (i) **False.** For example, $\sin(60^\circ + 30^\circ) = \sin 90^\circ = 1$, but $\sin 60^\circ + \sin 30^\circ = \dfrac{\sqrt{3}}{2} + \dfrac{1}{2} \neq 1$.
- (ii) **True.** In the interval $0^\circ$ to $90^\circ$, $\sin \theta$ increases as $\theta$ increases.
- (iii) **False.** In $0^\circ$ to $90^\circ$, $\cos \theta$ decreases as $\theta$ increases.
- (iv) **False.** $\sin \theta = \cos \theta$ only when $\theta = 45^\circ$, not for all $\theta$.
- (v) **True.** $\cot A = \dfrac{\cos A}{\sin A}$; at $A = 0^\circ$, $\sin 0^\circ = 0$, so cot A is not defined.
