## EXERCISE 4.1

1. Check whether the following are quadratic equations :
   - (i) $(x + 1)^2 = 2(x - 3)$
   - (ii) $x^2 - 2x = (-2)(3 - x)$
   - (iii) $(x - 2)(x + 1) = (x - 1)(x + 3)$
   - (iv) $(x - 3)(2x + 1) = x(x + 5)$
   - (v) $(2x - 1)(x - 3) = (x + 5)(x - 1)$
   - (vi) $x^2 + 3x + 1 = (x - 2)^2$
   - (vii) $(x + 2)^3 = 2x(x^2 - 1)$
   - (viii) $x^3 - 4x^2 - x + 1 = (x - 2)^3$

2. Represent the following situations in the form of quadratic equations :
   - (i) The area of a rectangular plot is 528 m². The length of the plot (in metres) is one more than twice its breadth. We need to find the length and breadth of the plot.
   - (ii) The product of two consecutive positive integers is 306. We need to find the integers.
   - (iii) Rohan's mother is 26 years older than him. The product of their ages (in years) 3 years from now will be 360. We would like to find Rohan's present age.
   - (iv) A train travels a distance of 480 km at a uniform speed. If the speed had been 8 km/h less, then it would have taken 3 hours more to cover the same distance. We need to find the speed of the train.

## Solutions

**1.** Check whether the following are quadratic equations (simplify and see if of the form $ax^2 + bx + c = 0$, $a \neq 0$) :

- (i) $(x+1)^2 = 2(x-3)$ $\Rightarrow$ $x^2 + 2x + 1 = 2x - 6$ $\Rightarrow$ $x^2 + 7 = 0$. Yes, quadratic.
- (ii) $x^2 - 2x = (-2)(3-x)$ $\Rightarrow$ $x^2 - 2x = -6 + 2x$ $\Rightarrow$ $x^2 - 4x + 6 = 0$. Yes, quadratic.
- (iii) $(x-2)(x+1) = (x-1)(x+3)$ $\Rightarrow$ $x^2 - x - 2 = x^2 + 2x - 3$ $\Rightarrow$ $-3x + 1 = 0$. No, linear.
- (iv) $(x-3)(2x+1) = x(x+5)$ $\Rightarrow$ $2x^2 - 5x - 3 = x^2 + 5x$ $\Rightarrow$ $x^2 - 10x - 3 = 0$. Yes, quadratic.
- (v) $(2x-1)(x-3) = (x+5)(x-1)$ $\Rightarrow$ $2x^2 - 7x + 3 = x^2 + 4x - 5$ $\Rightarrow$ $x^2 - 11x + 8 = 0$. Yes, quadratic.
- (vi) $x^2 + 3x + 1 = (x-2)^2$ $\Rightarrow$ $x^2 + 3x + 1 = x^2 - 4x + 4$ $\Rightarrow$ $7x - 3 = 0$. No, linear.
- (vii) $(x+2)^3 = 2x(x^2 - 1)$ $\Rightarrow$ $x^3 + 6x^2 + 12x + 8 = 2x^3 - 2x$ $\Rightarrow$ $-x^3 + 6x^2 + 14x + 8 = 0$. No, cubic.
- (viii) $x^3 - 4x^2 - x + 1 = (x-2)^3$ $\Rightarrow$ $x^3 - 4x^2 - x + 1 = x^3 - 6x^2 + 12x - 8$ $\Rightarrow$ $2x^2 - 13x + 9 = 0$. Yes, quadratic.

**2.** Represent in the form of quadratic equations :

- (i) Let breadth = $x$ m. Length = $(2x + 1)$ m. Area $= x(2x+1) = 528$ $\Rightarrow$ $2x^2 + x - 528 = 0$.
- (ii) Let the integers be $x$ and $x+1$. $x(x+1) = 306$ $\Rightarrow$ $x^2 + x - 306 = 0$.
- (iii) Let Rohan’s present age = $x$ years. Mother’s age = $(x+26)$ years. Three years from now: $(x+3)(x+29) = 360$ $\Rightarrow$ $x^2 + 32x + 87 = 360$ $\Rightarrow$ $x^2 + 32x - 273 = 0$.
- (iv) Let speed = $x$ km/h. Time = $\dfrac{480}{x}$ h. With speed $(x-8)$ km/h, time = $\dfrac{480}{x-8}$. So $\dfrac{480}{x-8} - \dfrac{480}{x} = 3$ $\Rightarrow$ $480x - 480(x-8) = 3x(x-8)$ $\Rightarrow$ $3840 = 3x^2 - 24x$ $\Rightarrow$ $x^2 - 8x - 1280 = 0$.
