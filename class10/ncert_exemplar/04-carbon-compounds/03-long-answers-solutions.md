# Unit 4: Long Answer Solutions

<ol start="47">
  <li>
    <p>Salt X: sodium ethanoate (CH3COONa). Gas: carbon dioxide (CO2).</p>
    <p>Test: Pass the gas through lime water; it turns milky due to CaCO3 formation.</p>
    <p>Equations:</p>
    <p>CH3COOH + NaHCO3 → CH3COONa + H2O + CO2</p>
    <p>CO2 + Ca(OH)2 → CaCO3↓ + H2O</p>
  </li>

  <li>
    <ol type="a">
      <li><p>Hydrocarbons are compounds of carbon and hydrogen only (e.g. methane CH4, ethene C2H4, ethyne C2H2).</p></li>
      <li><p>Saturated hydrocarbons (alkanes) have only single bonds (e.g. ethane, propane). Unsaturated hydrocarbons have at least one double or triple bond (e.g. ethene, ethyne).</p></li>
      <li><p>A functional group is an atom/group that decides characteristic reactions (e.g. —OH, —CHO, &gt;C=O, —COOH).</p></li>
    </ol>
  </li>

  <li>
    <p>Hydrogenation reaction (addition of hydrogen) is used to convert vegetable oils to fats using Ni/Pd catalyst. Unsaturated oils (C=C) add H2 to form saturated fats.</p>
  </li>

  <li>
    <ol type="a">
      <li><p>Carbon tetrachloride: CCl4. Carbon forms 4 single covalent bonds with 4 Cl atoms (tetrahedral).</p></li>
      <li><p>Saponification: alkaline hydrolysis of an ester to give a salt of acid (soap) and alcohol.</p>
      <p>RCOOR' + NaOH → RCOONa + R'OH.</p></li>
    </ol>
  </li>

  <li>
    <p>Prepare an ester (e.g. ethyl ethanoate) by heating ethanol with ethanoic acid in presence of conc. H2SO4, then pour into water and smell the fruity odour.</p>
    <p>CH3COOH + C2H5OH \(\xrightarrow{\text{conc. }H_2SO_4}\) CH3COOC2H5 + H2O.</p>
  </li>

  <li>
    <p>C: ethanoic acid (CH3COOH). R: sodium ethanoate (CH3COONa). A: ethanol (C2H5OH). S: ethyl ethanoate (CH3COOC2H5).</p>
    <p>Reactions:</p>
    <p>2CH3COOH + 2Na → 2CH3COONa + H2</p>
    <p>CH3COOH + NaOH → CH3COONa + H2O</p>
    <p>CH3COOH + C2H5OH \(\xrightarrow{\text{conc. }H_2SO_4}\) CH3COOC2H5 + H2O</p>
    <p>CH3COOC2H5 + NaOH → CH3COONa + C2H5OH</p>
  </li>

  <li>
    <ol type="a">
      <li><p>Lime water in tube B turns milky (CO2 forms CaCO3).</p></li>
      <li><p>In A: acid + NaHCO3 produces CO2. In B: CO2 + Ca(OH)2 → CaCO3↓ + H2O.</p></li>
      <li><p>No. Ethanol does not react with NaHCO3 like ethanoic acid.</p></li>
      <li><p>Add excess Ca(OH)2 to water, shake and filter; the filtrate is lime water.</p></li>
    </ol>
  </li>

  <li>
    <ol type="a">
      <li><p>Ethanol → ethene: dehydration using conc. H2SO4 at 443 K: C2H5OH → C2H4 + H2O.</p></li>
      <li><p>Propanol → propanoic acid: oxidation using KMnO4/K2Cr2O7: CH3CH2CH2OH → CH3CH2COOH.</p></li>
    </ol>
  </li>

  <li>
    <p>Isomers of C3H6O include propanal (CH3CH2CHO) and propanone (CH3COCH3). (Electron-dot structures to be drawn.)</p>
  </li>

  <li>
    <ol type="a">
      <li><p>Hydrogenation: C=C + H2 \(\xrightarrow{\text{Ni}}\) saturated compound.</p></li>
      <li><p>Oxidation: ethanol + [O] → ethanoic acid (using KMnO4).</p></li>
      <li><p>Substitution: CH4 + Cl2 \(\xrightarrow{\text{sunlight}}\) CH3Cl + HCl.</p></li>
      <li><p>Saponification: ester + NaOH → salt + alcohol.</p></li>
      <li><p>Combustion: hydrocarbon + O2 → CO2 + H2O.</p></li>
    </ol>
  </li>

  <li>
    <p>From combustion data: 1 mol C gives 2 mol CO2 and 3 mol H2O → compound C is C2H6 (ethane). Therefore B is C2H4 (ethene) and A is C2H5OH (ethanol).</p>
    <p>Equations:</p>
    <p>C2H5OH \(\xrightarrow{\text{conc. }H_2SO_4,\,443K}\) C2H4 + H2O</p>
    <p>C2H4 + H2 \(\xrightarrow{\text{Ni}}\) C2H6</p>
    <p>C2H6 + \(\frac{7}{2}\)O2 → 2CO2 + 3H2O</p>
  </li>
</ol>
